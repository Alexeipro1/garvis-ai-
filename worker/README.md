# J.A.R.V.I.S. API — защищённый посредник для Claude

Cloudflare Worker между приложением (GitHub Pages) и Anthropic Claude API.
**Ключ Anthropic хранится только здесь, в секретах Cloudflare** — не в репозитории, не в приложении, не в localStorage.

## Защита
- Без личного ключа доступа (`ACCESS_KEY`, 32+ символов) запросы получают 401. Ключ сравнивается за постоянное время.
- CORS: принимаются только запросы с `ALLOWED_ORIGIN` (адрес приложения).
- Ограничение частоты: 10 запросов/мин с одного адреса — до проверки ключа (защита от подбора). Счётчик приблизительный, по дата-центрам.
- Суточный лимит `DAILY_LIMIT` (по умолчанию 200) — глобальный счётчик в Durable Object (день по Asia/Jerusalem).
- Модель, системные инструкции и потолок ответа (1024 токена) задаются на сервере; приложение не может их изменить.
- Принимается не более 20 последних сообщений, до 2000 символов каждое, тело до 64 КБ.
- Содержимое переписки не логируется. Ошибки Anthropic наружу не раскрываются.

## Настройка с iPhone (Safari)

### 1. Anthropic: ключ и баланс
1. Зайдите в консоль Anthropic (console.anthropic.com), создайте аккаунт.
2. Пополните баланс (рекомендуется $5–10) и **не включайте автопополнение** — баланс станет жёстким потолком расходов. API оплачивается отдельно от подписки Claude.
3. Создайте API-ключ. Он показывается один раз: скопируйте его в буфер. **Никому не отправляйте его, в том числе в чат с Claude.**

### 2. Cloudflare: Worker
1. Зарегистрируйтесь на dash.cloudflare.com (бесплатный план достаточен).
2. Подключите репозиторий: *Workers & Pages* → создать приложение → импорт из GitHub → репозиторий `garvis-ai-`. Корневая папка (Root directory) — `worker`, команда сборки пустая, команда деплоя `npx wrangler deploy`. (Названия кнопок в панели Cloudflare могут немного отличаться.)
   Запасной путь — вручную запускаемый workflow `Deploy Worker (manual)` (нужны секреты репозитория `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`).
3. Откройте созданный Worker `jarvis-api` → *Settings* → *Variables and Secrets* → добавьте **секреты** (тип Secret):
   - `ANTHROPIC_API_KEY` — ключ из шага 1;
   - `ACCESS_KEY` — личный ключ доступа (создайте в приложении кнопкой «Сгенерировать ключ доступа» на вкладке «О системе»; он копируется в буфер).
4. Адрес Worker (вида `https://jarvis-api.<ваш-поддомен>.workers.dev`) показан на странице Worker.

### 3. Подключение в приложении
Вкладка «О системе» → «Подключение модели» → введите адрес Worker и ключ доступа → «Проверить и подключить». Проверка не обращается к Anthropic и не тратит деньги.

## Смена модели и лимитов
Переменные `MODEL`, `DAILY_LIMIT`, `ALLOWED_ORIGIN` лежат в `wrangler.toml` (это не секреты). Измените файл на GitHub (кнопка «карандаш») и слейте в `main` — Worker обновится сам. Значения, изменённые только в панели Cloudflare, будут перезаписаны следующим деплоем.

- `claude-haiku-5-5` — самая дешёвая (≈ $0,5–1,5 в месяц при ~50 сообщениях в день).
- `claude-sonnet-5-5` — заметно лучше в свободной беседе (≈ $8–20 в месяц).

## Если ключ доступа утёк
Задайте новое значение секрета `ACCESS_KEY` в Cloudflare и введите новый ключ в приложении. Для ключа Anthropic — отзовите его в консоли Anthropic и создайте новый.

## Разработка
```bash
cd worker
npm install
npm run typecheck
npm test                      # проверка логики на подменённой модели, без сети
echo 'ACCESS_KEY=<40+ символов>' > .dev.vars
echo 'ANTHROPIC_API_KEY=<тестовый ключ>' >> .dev.vars   # файл в .gitignore
npm run dev
```
